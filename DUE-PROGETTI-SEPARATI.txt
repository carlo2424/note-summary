IN COMUNE (voluto)
  • Token GitHub Gist nelle Impostazioni: incollalo una volta;
    le due app condividono solo quel token (non i dati).
  • Stesso account GitHub, ma file gist diversi:
    - note-personali-backup.json
    - note-summary-backup.json

SEPARATI (non si mescolano più sul telefono)
  • Database sul dispositivo (cartelle diverse)
  • Backup cloud (gist id dedicato per app)
  • Nome e icona «Aggiungi a schermata Home»
  • Menu in basso (Personali: Spese; Summary: Trading/Crypto)

SE VEDI MENU O ICONE SBAGLIATE
  1. Apri il link GIUSTO nel browser (vedi tabella sopra).
  2. Elimina dalla Home l’icona vecchia.
  3. Aggiungi di nuovo a schermata Home dal sito corretto.

Dopo l’aggiornamento «due progetti», Note Summary usa un database
nuovo (NoteSummaryDB). Se avevi solo dati locali nella vecchia
installazione condivisa, usa Impostazioni → ripristina da gist
oppure backup manuale.
